# 🥕 김당근 미식 — 미식 지도 & 맛집 검색기

전국 3,400여 곳을 모은 미식 지도. 상호명·동네·메뉴·태그를 **초성까지** 실시간 검색하고,
지역·분류 필터와 **취향 학습 무한 발굴**로 끝없이 새 맛집을 찾습니다.

- 라이브: https://kimdanggeun.github.io/
- ✨ 무한 발굴(5곳): 아직 안 본 곳만 5곳씩. 가봄·별점·댓글·지도 클릭·필터 선택을 학습해 취향에 가깝게 뽑습니다.
- 📡 실시간 발굴: OpenStreetMap(Overpass API, 막히면 Nominatim)에서 선택한 동네의 실제 식당을 실시간으로 캐옵니다. API가 느리거나 막히면 3,400곳 미노출 풀에서 즉시 채웁니다.
- 🗺️ 네이버지도 / 🌍 구글지도: 네이버는 '상호명+구/시'로 검색(주소를 붙이면 업체를 못 찾는 문제 수정), place ID가 있으면 해당 업체 페이지로 바로 연결
- ✨ 파인다이닝: 미쉐린 스타·셀렉티드, 호텔 파인다이닝, 오마카세·코스 다이닝만 남긴 큐레이션(36곳)
- 별점·댓글·가봄 기록·취향 학습은 서버로 보내지 않고 브라우저(localStorage)에만 저장됩니다.

정적 HTML 한 장(`index.html`)으로 동작합니다.
